How it works

One scene. Many hands.

Shared scene

Everyone in a server edits the same 3D world: boxes, spheres, cylinders, planes and lights.

Live sync

Every move, rotate, scale and recolor shows up instantly for everyone. The database is the source of truth.

Object locking

Select an object and it's yours. Others see your outline and name in your color until you let go.

Presence

A live panel shows who's in the scene, so you always know who you're building with.
